## 개요
> 이 PR에서 변경한 내용을 간략하게 설명해주세요.

`GET /api/gatherings/{id}/members` 모임 멤버 목록 조회 API를 더미 응답에서 실제 DB 조회로 교체했습니다.
참여 멤버를 HOST 우선·참여순으로 페이징 반환하며, 사용자 정보를 N+1 없이 로딩합니다.

## 변경 사항
- `GatheringMemberRepository.findByGatheringId(Long, Pageable)` 추가 — `@EntityGraph(user)` 로 사용자 함께 로딩(N+1 회피), 정렬은 Pageable 주입.
- `GatheringMemberService.getMembers(gatheringId, page, size)` 신규 — 모임 존재 검증(`GATHERING_NOT_FOUND`) → HOST 우선(role STRING 오름차순) + 참여순(joined_at) 정렬 조회 → 학과명 배치 매핑 → `PageResponse` 변환. campus 는 기능 제외로 null.
- `GatheringMemberController.getGatheringMembers` — 더미 제거, 서비스 연결.

**참고**
- 비로그인 조회 허용(기존 컨트롤러에 인증 요구 없음). 멤버 목록은 민감정보(학과/역할)만 노출, campus·태그 없음.
- `ErrorCode` 변경 없음(`GATHERING_NOT_FOUND` 재사용).
- "모임 나가기"(`DELETE .../members/me`)는 이번 이슈 범위 밖이라 더미로 남겨뒀습니다(방장 위임/탈퇴 정책 필요 → 별도 이슈 권장).
