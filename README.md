# 2gether_BE
> 대학생들이 캠퍼스와 전공의 경계를 넘어 자연스럽게 연결될 수 있도록 돕는 모임 기반 교류 플랫폼

## 프로젝트 소개

**유대감(U-DayGam)** 은 같은 대학 안에서도 접점이 적은 학생들이  
모임, 채팅, 활동 인증을 통해 자연스럽게 교류할 수 있도록 돕는 서비스입니다.

사용자는 학교 이메일 인증을 통해 대학 구성원임을 확인하고,  
관심사, 역량, 가용 일정, 학과 정보를 기반으로 모임을 생성하거나 참여할 수 있습니다.

또한 모임이 확정되면 그룹 채팅방이 생성되고,  
활동 완료 후 인증 사진과 후기를 업로드하면 Campus Canvas에 교류 기록이 반영됩니다.

---

## 주요 기능

- 회원가입 및 로그인
- 학교 이메일 인증
- 온보딩 프로필 설정
- 취미 태그 및 역량 태그 등록
- 가용 일정 등록
- 모임 생성 및 조회
- 모임 신청, 수락, 거절
- 모임 확정 후 그룹 채팅방 생성
- 6자리 코드 기반 안심 커넥트
- 활동 인증 업로드
- Campus Canvas 교류 기록 반영
- AI 기반 모임 추천 및 아이디어 분석
